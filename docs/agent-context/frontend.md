# Frontend Agent Context

## Mission
Implement the usable Mini Hong Kong map experience without turning the app into a marketing page.

## Required UI
- Directory-style main menu with small menus for Rail, Light Rail, Buses, Ferries, Trams, Flights, Data Status, and Settings.
- Hong Kong-centered MapLibre map.
- MTR and Light Rail lines, station markers, moving vehicles, time controls, language switcher, and 2D/3D toggle.

## Constraints
- Keep `App` as composition glue.
- Keep text readable on mobile and desktop.
- Do not add placeholder sections beyond planned-mode menu entries.
